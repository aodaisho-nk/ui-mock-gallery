## 0. AIに渡すときの最初の一文

> 以下の指示書のとおり、採用管理システム（ATS）のダッシュボード画面を作ってください。
> 単一のHTMLファイルで、外部通信（fetch・CDN・外部フォント・iframe）は一切行わず、データはすべて指示書のダミーを埋め込みでお願いします。
> グラフはCSS（conic-gradient・div の幅指定）とインラインSVGだけで描き、ライブラリは使わないでください。
> 1280px幅のノートPCで横スクロールが出ないことを最優先にしてください。

---

## 1. この画面の目的

商談の冒頭20秒で「朝いちばんに開く画面」として見せ、そのあと**「集計しなくても、文章で聞けば分析が返ってくる」**ところまで一気に持っていく。

見せたい順は3つだけ。

| 順 | 見せるもの | 言う言葉 |
| --- | --- | --- |
| ① | KPI 4枚＋要対応 | 「未対応3件、今日の面接2件。ここだけ見れば今日が分かります」 |
| ② | フリーワード分析 | 「集計表を作らなくていいんです。**聞けば出ます**」 |
| ③ | レポート抽出 → 格納 → メール | 「そのまま報告資料になって、所定の場所に入って、チームに届きます」 |

商談相手は **採用担当1〜3名で回している中小企業**。現状はスプレッドシート＋媒体管理画面＋カレンダーの行き来。

---

## 2. 絶対に守ること

1. **実在の人物・企業・媒体名を出さない。** 媒体は「媒体A/B/C」「採用ホームページ」。媒体のロゴは貼らない。
2. **数字を自己矛盾させない。** §6の数値は合計・構成比・歩留まりがすべて合うように作ってある。1つ変えたら関連も直す。
3. **「AIが自動で判断します」と書かない。** フリーワード分析は**辞書によるワード抽出＋固定の集計**であることを、画面の注記で明示する。
4. **デモ値であることを画面に残す。** レポート本文とフリーワード分析の末尾に「デモのため、数値は固定データです」を入れる。
5. **外部通信なし。** 画像が要るならインラインSVGで描く。

---

## 3. 技術の前提

- 出力: **単一のHTMLファイル**（CSS・JSを同じファイルに内包）
- 表示幅: **1280px基準**、1024pxでも崩れないこと。スマホ対応は不要
- 画面切替: 左メニューのクリックで `section` を `hidden` で出し分ける。URLは変えない
- グラフ: ドーナツ＝`conic-gradient`、横棒＝`div` の `width` 指定、縦棒＝`div` の `height` 指定。**ライブラリ禁止**
- アニメーション: 150ms程度のフェード、チェックの順次表示（420ms間隔）まで。派手な演出は不要
- フォント: `"Hiragino Kaku Gothic ProN","Yu Gothic","Meiryo",sans-serif`／本文14px

## 6. フリーワード分析の詳細仕様 → **図: `fig2-freeword.svg`**

### 6.1 状態遷移

| 時刻 | 表示 |
| --- | --- |
| 0ms | スピナー＋「入力された文章からワードを抽出しています…」 |
| 700ms | 文言だけ差し替え「該当データを集計し、分析項目を組み立てています…」 |
| 1500ms | 「✅ 分析が完了しました（N個のワードを認識／分析項目を4件生成）」＋結果を描画 |

**この2段階の切替が、商談で一番効く演出。必ず入れること。** 一気に出すと「用意してあるだけ」に見える。

### 6.2 ワード辞書（`DICT`）

4カテゴリ。値は `[表示ラベル, [マッチする語…]]`。

```js
const DICT={
 期間:[["直近3日間",["直近3日","直近三日","ここ3日","過去3日"]],["今週",["今週"]],["先週",["先週"]],
      ["今月",["今月"]],["直近7日間",["直近7日","1週間","一週間"]],["全期間",["全期間","累計"]]],
 比較対象:[["全クール平均",["全クール","全体","平均"]],["2026年7月クール",["7月クール","7月"]],
      ["2026年5月クール",["5月クール","5月"]],["前週",["前週","先週比"]]],
 分析軸:[["媒体別",["媒体別","媒体","チャネル"]],["流入経路別",["流入","経路","ランディング"]],
      ["職種別",["職種別","営業職","事務職"]],["面接官別",["面接官"]]],
 指標:[["応募数",["応募数","応募"]],["有効応募率",["有効応募率","有効"]],["1次設定数",["1次設定","設定数","1次"]],
      ["1次実施数",["実施数","実施"]],["通過率",["通過"]],["内定・承諾",["内定","承諾"]],
      ["応募率",["応募率"]],["滞在時間",["滞在"]]]
};
```

**パース規則**

1. 入力文字列に対し `String.includes` で全カテゴリを走査し、ヒットしたものを配列で返す
2. 期間が1つも取れなければ先頭に「直近7日間」を補う
3. 指標が取れなければ末尾に「応募数」を補う
4. 分析軸が取れなければ末尾に「媒体別」を補う

**補完を必ず入れること。** どんな入力でも必ず結果が出るようにしておかないと、商談でその場の思いつきを入力されたときに画面が白くなる。

### 6.3 出力（上から順に5ブロック）

**① 認識ワードのチップ**

```
[期間 直近3日間 ✕] [比較対象 全クール平均 ✕] [分析軸 媒体別 ✕] [指標 応募数 ✕]
```

白地・`--accent` の枠・角丸13px。カテゴリ名は10pxで `--sub`、ラベルは太字で `--accent`。✕クリックで `this.parentNode.remove()`（再集計はしない）。

**② 分析カード4枚**（`grid-template-columns: repeat(4,1fr); gap:10px`）

見出しは**認識ワードから組み立てる**こと。数値は固定でよい。

| 見出しテンプレート | 値 | 差分行 |
| --- | ---: | --- |
| `${期間}の応募数` | 11 件 | 1日あたり 3.67件 |
| `${比較対象} との差（1日あたり）` | +93% | 3.67件 / 1.90件（緑） |
| `${期間}の有効応募率` | 81.8 % | 全クール平均 80.0%（緑） |
| `${分析軸}で最も伸びた項目` | 採用HP | 構成比 29.2% → 45.5%（緑） |

**③ 比較テーブル**（2段ヘッダ。上段は期間名を colspan=3 で結合）

行＝媒体5つ＋合計行。列＝`応募数 / 有効応募 / 構成比` を2期間分。

**④ 所見コメント**（`--accent-soft` の地・左3px線）

「読み取れること」として3〜4文。末尾に11pxで「※ デモのため、数値は2026年7月クール（営業職）の固定データを表示しています。」

**⑤ フッタ行** … 左に注記（hint）、右端に ［📄 レポートを抽出］（`.btn.pri`）

## 7. レポート抽出フロー → **図: `fig3-report.svg`**

オーバーレイ1枚（幅520px）の中身を3段階で差し替える。

### STEP 1　設定（`#repStep1`）

- 緑ヘッダ「📄 分析レポートを作成 / この分析結果をレポートにして、指定の場所へ格納します」
- 条件サマリ（`--accent-soft` の地）＝直前の分析の期間・比較対象・分析軸
- プルダウン3つ

| 項目 | 選択肢 |
| --- | --- |
| 形式 | PDF ＋ スプレッドシート／PDFのみ／スプレッドシートのみ |
| 格納先 | 共有ドライブ ＞ 採用 ＞ 2026年7月クール ＞ 分析レポート／共有ドライブ ＞ 採用 ＞ 月次報告／共有ドライブ ＞ 経営会議資料 ＞ 2026年7月 |
| 通知先 | 採用チーム（3名）／採用チーム＋役員（5名）／自分だけ |

- ［キャンセル］［作成して格納する］

### STEP 2　進行（`#repStep2`）

5行を **300ms + n×420ms** で1行ずつ表示（`opacity:0→1`・左から6pxスライド）。右上のステータスは「処理中…」→ 2350msで「✅ 完了」。

1. 分析条件を確定 … `${期間} × ${比較対象}／${分析軸}`
2. 集計データを書き出し … 7シート／18項目・グラフ4点を生成
3. レポートを生成 … 選択した形式を表示
4. 指定の格納先へ保存 … 選択した格納先を表示
5. 社内通知メールを送信 … 選択した通知先を表示

**選んだ設定が各行に出ることが重要。** 「ちゃんと設定が効いている」と伝わる。

### STEP 3　完了（`#repStep3`）／ 2700ms後

- ファイルカード2枚（PDF＝赤アイコン／XLSX＝緑アイコン）
  ファイル名は `採用分析レポート_20260717_0941_${期間}vs${比較対象}.pdf`
- 格納先パス＋［フォルダを開く］
- **届いたメールのプレビュー**（右上に「✅ 送信しました」）

```
宛先　採用チーム（3名）
件名　【採用分析】直近3日間と全クール平均の比較レポート
本文　お疲れさまです。採用管理システムの自動通知です。
　　　ご依頼の分析レポートを作成し、下記へ格納しました。
　　　　格納先：（選択した格納先）
　　　　ファイル：（生成したファイル名）
　　　要点：
　　　・直近3日間の応募は1日あたり3.67件で、全クール平均（1.90件）を93%上回っています。
　　　・伸びの中心は採用ホームページ経由で、構成比が29.2%→45.5%に上がりました。
　　　・有効応募率は81.8%（全クール平均は80.0%）で、ほぼ横ばいです。
```

- ［⏰ 定期作成に登録］（毎週月曜08:00）
- ［閉じる］［👁 レポートを開く］

### STEP 4　レポートビューア（別オーバーレイ・幅840px）

- 黒いドキュメントバー（ファイル名＋格納先／ダウンロード・印刷・閉じる）
- グレー背景に**A4を模した白いページ1枚**（幅700px・padding 34px 42px・影付き）

ページ構成:

1. ヘッダ（`--accent` の3px下線／タイトルは `${期間}と${比較対象}の比較`／クール・職種・分析軸・作成日時・「作成：採用管理システム（自動）」）
2. サマリー … KPI4枚
3. 応募数の推移 … 3日分の**縦棒グラフ**（濃色＝総応募／淡色＝有効応募）に、全クール平均1.90件/日の**破線**（`--warn`）を重ねる
4. 分析軸の比較 … 媒体別テーブル
5. 所見 … 3段落
6. 次のアクション（案） … 優先／内容／担当／期限の3行
7. フッタ「採用分析レポート ／ 管理会社A社」「1 / 1」
8. ページ外に「※ デモ用のサンプルレポートです。数値はすべて架空のものです。」
